## What it does

Structural antipatterns is the design-control lens for structural misfit and avoidable tax. It treats the catalog as search lenses, not a checklist, and reports only evidence-backed owner, information, mechanism, or proof gaps.

## When to reach for it

Type `/structural-antipatterns`, or the agent reaches for it automatically when system design, module boundaries, proof claims, or overengineering need review.

Reach for it before accepting a plan or implementation that changes system shape, especially when a wrapper, workaround, proxy proof, or custom pipeline smells like permanent tax.

## Where it fits

It supports [root](https://aihero.dev/skills-root), [codebase-design](https://aihero.dev/skills-codebase-design), and [architecture-council](https://aihero.dev/skills-architecture-council). [ask-matt](https://aihero.dev/skills-ask-matt) routes the wider set.
