# Misc

Tools kept around for less frequent or specialized work. They are not promoted
in the plugin and remain available from a repository clone.

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)** — Set up Claude Code hooks to block dangerous git commands before they execute.
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)** — Migrate test files from `as` type assertions to `@total-typescript/shoehorn`.
- **[scaffold-exercises](./scaffold-exercises/SKILL.md)** — Create exercise directories with sections, problems, solutions, and explainers.
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)** — Set up Husky hooks with lint-staged, formatting, type checking, and tests.
- **[architecture-premise-audit](./architecture-premise-audit/SKILL.md)** — Audit whether the whole system archetype is wrong before trusting existing boundaries.
- **[repo-refresh](./repo-refresh/SKILL.md)** — Remove explicitly requested stale docs, plans, proof machinery, scripts, and generated debris.
- **[structural-antipatterns](./structural-antipatterns/SKILL.md)** — Detect structural misfit, weak-owner workarounds, proof laundering, and overengineering.
- **[ultra-review](./ultra-review/SKILL.md)** — Run a maximum-recall peer review and preserve every candidate.
