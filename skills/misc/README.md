# Misc

Tools kept around for less frequent or specialized work. They are not promoted
in the plugin, but remain available from a repository clone.

- **[git-guardrails-claude-code](./git-guardrails-claude-code/SKILL.md)** — Set up Claude Code hooks to block dangerous git commands (push, reset --hard, clean, etc.) before they execute.
- **[migrate-to-shoehorn](./migrate-to-shoehorn/SKILL.md)** — Migrate test files from `as` type assertions to @total-typescript/shoehorn.
- **[scaffold-exercises](./scaffold-exercises/SKILL.md)** — Create exercise directory structures with sections, problems, solutions, and explainers.
- **[setup-pre-commit](./setup-pre-commit/SKILL.md)** — Set up Husky pre-commit hooks with lint-staged, Prettier, type checking, and tests.
- **[architecture-premise-audit](./architecture-premise-audit/SKILL.md)** — Audit whether the whole system archetype is wrong before trusting existing boundaries and vocabulary.
- **[codebase-design](./codebase-design/SKILL.md)** — Design deep modules with small interfaces, clean seams, and high leverage.
- **[domain-modeling](./domain-modeling/SKILL.md)** — Sharpen domain terminology, scenarios, context, and ADRs.
- **[grill-with-docs](./grill-with-docs/SKILL.md)** — Grill a plan while building the domain model and decision docs.
- **[improve-codebase-architecture](./improve-codebase-architecture/SKILL.md)** — Scan for codebase deepening opportunities and produce a visual report.
- **[peer](./peer/SKILL.md)** — Repository reference for the embedded `codex-peer` role contract.
- **[prototype](./prototype/SKILL.md)** — Build a throwaway prototype to answer a design question.
- **[repo-refresh](./repo-refresh/SKILL.md)** — Remove explicitly requested stale docs, plans, proof machinery, scripts, and generated debris.
- **[resolving-merge-conflicts](./resolving-merge-conflicts/SKILL.md)** — Resolve an in-progress merge or rebase conflict hunk by hunk.
- **[root](./root/SKILL.md)** — Repository reference for the embedded `codex-root` role contract.
- **[structural-antipatterns](./structural-antipatterns/SKILL.md)** — Detect structural misfit, weak-owner workarounds, proof laundering, and overengineering.
- **[supervisor](./supervisor/SKILL.md)** — Repository reference for the embedded `codex-supervisor` role contract.
- **[triage](./triage/SKILL.md)** — Move issues and external PRs through the configured triage state machine.
- **[ultra-review](./ultra-review/SKILL.md)** — Run a maximum-recall peer review and preserve every candidate.
- **[wayfinder](./wayfinder/SKILL.md)** — Map a very large effort as decision tickets until the route is clear.
